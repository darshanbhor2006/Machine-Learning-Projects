# 🎓 Placement Intelligence AI

> **Predictive Analytics & Career Readiness Dashboard**

A modern Machine Learning web application that predicts student placement opportunities using academic and profile metrics. Built with **Python, Flask, Scikit-Learn**, and an interactive dashboard, this project helps educational institutions and students assess placement readiness through predictive analytics.

---

## 🚀 Features

- 🎯 Predicts student placement eligibility
- 🤖 Machine Learning Classification Model
- 📊 Interactive and responsive dashboard
- 📈 Feature importance visualization
- 📝 Automatic prediction history logging
- ⚡ Real-time predictions
- 🌐 Flask-powered web application
- 💾 Pre-trained model using Pickle

# 💡 How It Works

1. Enter the student's CGPA, IQ, and Profile Score.
2. Click **Predict Placement**.
3. The trained Machine Learning model processes the input.
4. The application predicts whether the student is likely to be **Placed** or **Not Placed**.
5. Every prediction is automatically saved in `prediction_history.csv`.
